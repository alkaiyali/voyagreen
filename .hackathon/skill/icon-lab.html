Every glyph below is the set you picked. Switch it in the controls — the nav, the action rail, the counts and the spinning disc all follow. One icon family across a whole UI is what makes it read as designed.

Icons are inlined as SVG, so they inherit currentColor, scale with the slot, and cost no icon font, no sprite and no JS runtime. The page fetches each set's data once (19 requests, cached in your browser) instead of one request per icon — which is what the public Iconify API can actually survive.
